# Muhammad Ahmad's portfolio

A React portfolio focused on backend engineering, automation, and eight selected projects.

## Run locally

```bash
npm install
npm run dev
```

## Check and build

```bash
npm run lint
npm run build
```

The production site is written to `dist/`. Any static hosting service that supports Vite works: build with `npm run build` and publish `dist/`.

## Content and privacy

The project descriptions are intentionally high level. This public repository does not contain code or detailed documentation from GWG Platform, ATTDE, or SpexBot.
